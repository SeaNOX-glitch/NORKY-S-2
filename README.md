# Norky's — Sistema de pedidos web

Proyecto listo para abrir en Visual Studio Code.

## Cómo ejecutarlo

1. Descomprime la carpeta `norkys-web`.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html`.
4. Puedes ejecutarlo directamente en el navegador o usar la extensión **Live Server** de VS Code.
5. Si usas Live Server: clic derecho en `index.html` → **Open with Live Server**.

## Funcionalidades

- Catálogo de 3 productos basado en el proyecto.
- Selección de producto.
- Selector de cantidad.
- Consumo en local / Delivery.
- Complementos.
- Cálculo automático de subtotal.
- Descuento del 10% si subtotal > S/ 120.
- Delivery gratis si subtotal > S/ 80; en caso contrario S/ 8.
- Carrito de compras.
- Eliminación de productos.
- Confirmación de pedido y número de pedido.
- Diseño responsive para PC y celular.

## Archivos

- `index.html` → estructura de la página.
- `css/styles.css` → diseño y estilos.
- `js/app.js` → lógica del sistema.
